## 🌟 v3.0.0 核心特色与系统全景 (Milestone Highlights)

本项目历经 4 大重大迭代（Sprint 1 ~ 4），从最初的基础文字选择演进为兼具深度、数值策略与极高重复可玩性的轻度 Rogue-lite 职场生存小游戏：

### 1. 🗺️ Rogue-like DAG 地下城探索地图 (Sprint 1)
- **Mulberry32 种子伪随机数引擎 (PRNG)**：保障同日或同种子地图具备 100% 确定性复现机制。
- **10,000+ DAG 随机图零死角连通性验证**：严格拓扑验证算法，确保无论路线如何分支分叉，每一局必定拥有通往 1F 大堂的完整通路，绝无死胡同。
- **四维动态节点网络**：工位核心区 ➔ 走廊茶水间 ➔ 电梯消防厅 ➔ 一楼大堂闸机，包含安全避风港、补给点、危机突发点与隐藏通道。

### 2. 🔨 职场黑产工坊与道具羁绊系统 (Sprint 1)
- **无序材料合成引擎**：任意放入 2 件基础道具，自动比对职场黑产合成图鉴。
- **8 大传说神装合成配方**：
  - ⚡ **赛博兴奋剂**（风油精 + 咖啡）：立即恢复 40 体力，后续 4 次行动体力消耗归零且不耗时间！
  - 🕴️ **究极替身傀儡**（椅背外套 + 降噪耳机）：留置工位假人，锁定查岗怀疑度增加为 0。
  - 💣 **职场正道核弹**（《劳动法》+ 离职草稿）：面对高管盘问降维打击秒杀，怀疑度骤降 50%！
  - 🛴 **顺丰闪送全家桶**（反光黄马甲 + 零食大礼包）：大堂前台与安保视你为空气，直通货梯滑梯。
  - ☕ **架构师无敌气场**（厚项目书 + 墨镜）：自带架构师从容光环，怀疑度每回合自然衰减 3%。
  - 🛡️ **绝对防窥屏障**（更新蓝屏 + 保洁工卡）：电脑与通道全息锁死，彻底杜绝突击抓包。
  - 💨 **战术烟雾对讲机**（软中华 + 模拟通话）：制造虚假警报，阻断 Boss 巡逻路线 3 回合。
  - 🚨 **P0级核聚变工单**（甩锅工单 + 肠胃药盒）：双重不可抗力护体，秒杀任何会议强制拉扯！

### 3. 🤝 NPC 人脉好感度网络 (Sprint 2)
- **5 大特色职场 NPC**：
  - 👨‍💻 **阿伟（摸鱼战友）**：通风报信，群内打掩护，赠送零食即可结为莫逆之交。
  - 👔 **阿强（需求刺客产品经理）**：随时可能抱笔记本杀来，好感度低时疯狂堵门。
  - 🍵 **刘姐（HR总监）**：端着枸杞茶巡视价值观，出示《劳动法》或高情商对话方能化解。
  - 🚬 **保安老王（大厦真正话事人）**：送上一盒软中华，直接为你开启地下车库 VIP 免刷卡通道。
  - 🍰 **行政阿花（下午茶使者）**：掌握下午茶补给情报，赠送风油精可换取独家后勤通告。
- **好感度状态机**：数值在 `[-100, +100]` 区间动态流转，涵盖【宿敌】、【冷淡】、【中立】、【友善】与【铁血盟友】五重阶梯，解锁专属被动特权与出逃捷径。

### 4. 🎮 三大职场特色交互小游戏 (Sprint 2)
- 🗣️ **大厂黑话对决 (Buzzwords Duel)**：面对高管灵魂拷问，组合“维度打击”、“底层逻辑”、“赋能闭环”、“抓手协同”等高深黑话词组，评分 ≥ 80 即可将领导当场忽悠退散！
- 🧧 **微信红包排雷战 (Red Packet Minefield)**：17:58 阎总在群里发“攻坚补贴”红包。抢第一鸟？大概率两分钱被抓壮丁；尾刀捡漏？安全回体；若与阿伟好感极高，阿伟会提前私聊预警红包地雷！
- ⏱️ **18:00:00 准点打卡 QTE 判定**：毫米级读秒窗口！`-200ms ~ +500ms` 判定为 **PERFECT** 神仙出逃；过早点击按早退处置，过晚点击将招致怀疑度惩罚。

### 5. 📡 Boss 巡视雷达与声东击西战术 (Sprint 3)
- **Boss 实时楼层移动追踪**：阎总在 19F、18F、15F、3F 设备层与 1F 大堂之间巡回穿梭，雷达实时提供 `Safe 🟢` / `Warning 🟡` / `Danger 🔴` 威胁等级预警。
- **声东击西诱饵战术**：打翻茶水间微波炉、触发虚假火警、拨打大客户外放通话，将阎总从关键走廊直接引开 2~3 个回合！

### 6. 📅 每日职场老黄历与混沌词条叠加 (Sprint 3)
- **确定性每日运势生成**：基于真实系统日期种子，每天生成专属“宜摸鱼/忌提测/幸运道具”老黄历加成。
- **混沌词条自由堆叠**：支持叠加【阎总暴走日】、【全司内网宕机】、【季度OKR决战周】，当满足特定组合时激活传说级【末日周五 (Doomsday Friday)】复合极端挑战！

### 7. 👑 两大突破性游戏模式 (Sprint 4)
- 🏢 **逆转 Boss 模式 (Reverse Boss Mode - 阎王铁腕)**：
  - **身份反转**！你将化身大 Boss 阎总，初始坐拥 100 点管理威严值（Majesty）。
  - 运用专属技能【全员夺命@】（全员怀疑度暴涨）、【突击工位大搜查】、【高管电梯伏击】。
  - 在 18:05 前成功抓捕 3 名以上准点逃跑的员工，召开通宵闭门会，达成专属 **EX** 级统治结局！
- 🌙 **深夜加班大逃杀 (Nightmare Overtime Survival - 通宵噩梦)**：
  - **极限生存挑战**！从周五 20:00 熬到周六清晨 06:00（整整 20 个极限回合）。
  - 三重计量表平衡：**清醒值 (Sanity)**、**精力 (Energy)**、**存在感 (Presence)**。
  - 存在感必须精巧维持在 `[20, 60]` 的安全黄金区间：太低会被阎总点名批评，太高会被强塞 P0 级攻坚任务！
  - 成功熬到朝阳初升即可加冕 SSS+ 级【晨曦不灭战神】！

### 8. 🏆 26 大讽刺幽默多元结局与 25 大成就徽章 (Sprint 4)
涵盖 SSS+, SS, S, A, B, C, F, EX 全等级评级体系，尽显职场百态：
- 🥇 **神仙准点打卡 (SSS)**、🕴️ **替身使者·金蝉脱壳 (S)**、🏃 **楼梯疾风特工 (A)**、👑 **反客为主·画饼天尊 (SS)**；

## ☁️ Cloudflare Pages CI/CD 持续集成与部署

本项目已预置 GitHub Actions 工作流与 `wrangler.jsonc` 配置文件，完美适配全球 CDN 加速部署。

### 方式一：连接 GitHub 仓库自动集成（官方最推荐 ⭐⭐⭐⭐⭐）
1. 访问 [Cloudflare Dashboard](https://dash.cloudflare.com/)；
2. 依次点击 **Compute (Workers) & Pages** ➔ **Create application** ➔ **Pages** ➔ **Connect to Git**；
3. 授权并选中你的 `escape-work` GitHub 仓库；
4. 构建参数填写：
   - **Framework preset**: `Vite` (或选择 `None`)
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. 点击 **Save and Deploy**，Cloudflare 将在几十秒内完成全球节点部署并生成专属 `https://<你的项目名>.pages.dev` 域名！

### 方式二：GitHub Actions 自动持续部署
仓库已配置 `.github/workflows/deploy-cloudflare.yml`：
- 每次向 `main` 分支提交代码时，GitHub Actions 会自动执行 `npm ci` ➔ `npm test` 单元测试 ➔ `npm run build` 编译打包。
- 若在 GitHub 仓库 **Settings > Secrets and variables > Actions** 中添加了：
  - `CLOUDFLARE_API_TOKEN`（需具备 Cloudflare Pages 编辑权限）
  - `CLOUDFLARE_ACCOUNT_ID`（Cloudflare 账户 ID）
- 工作流将自动调用官方最新 `cloudflare/wrangler-action@v3` 将 `dist` 产物无缝发布至 Cloudflare Pages！若未配置 Secrets，CI 测试与构建仍将顺利通过并点亮绿色对勾。

### 方式三：Wrangler 命令行一键本地部署
```bash
# 1. 登录 Cloudflare
npx wrangler login

# 2. 编译并一键推送
npm run build
npx wrangler pages deploy dist --project-name=escape-work
```
