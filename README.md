## 🚀 本地快速启动

项目基于原生 ES Modules + Vite 构建，轻量纯粹无沉重依赖：

```bash
# 1. 克隆或进入项目目录
cd escape-work

# 2. 安装依赖 (仅需 Vite)
npm install

# 3. 启动本地开发服务器
npm run dev

# 4. 打包构建 (输出到 dist 目录，耗时约 0.1 秒)
npm run build

# 5. 本地预览生产构建产物
npm run preview
```

## ☁️ 部署到 Cloudflare Pages

本项目专为 Cloudflare Pages 设计，零服务端依赖，支持全球 CDN 毫秒级加载。

### 方式一：连接 GitHub 仓库自动部署（推荐 ⭐⭐⭐⭐⭐）

1. 将当前项目推送到你自己的 GitHub 仓库（参考下方 Git 提交指引）。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)。
3. 点击左侧导航栏 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
4. 选择你的 `escape-work` 仓库，并在构建配置中填写：
   - **Framework preset**: `Vite` (或选择 `None`)
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. 点击 **Save and Deploy**，即可在几十秒内获得专属的 `https://<你的项目名>.pages.dev` 全球访问链接！
6. 后续每次往 GitHub `main` 分支推代码，Cloudflare Pages 会自动触发编译部署。

### 方式二：使用 Cloudflare 仪表盘直接拖拽上传

1. 在本地终端执行打包：
   ```bash
   npm run build
   ```
2. 登录 Cloudflare 控制台，进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Upload assets**。
3. 将项目根目录下的 `dist` 文件夹直接拖拽上传。
4. 点击 Deploy 即可立即上线！

### 方式三：使用 Wrangler 命令行发布

已预置 `wrangler.jsonc` 配置文件：

```bash
# 1. 全局或临时运行 wrangler 登录（首次）
npx wrangler login

# 2. 一键发布 dist 目录到 Cloudflare Pages
npx wrangler pages deploy dist --project-name=escape-work
```
