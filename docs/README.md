# 《逃离大厂》项目设计与研发文档库

本目录汇集了《逃离大厂》（escape-work）v2.0 玩法扩展的完整设计规范、技术架构与工程排期文档。

---

## 📚 文档索引

1. **[玩法设计规范（GDD）](./GDD_EXPANSION_SYSTEMS.md)**
   * **内容**：分支节点地图（DAG）、职场人脉好感度网络、道具合成与羁绊神装、黑话大乱斗/红包排雷/打卡QTE等微交互、动态巡逻视野雷达、每日职场黄历天梯榜、阎总抓人模式与深夜通宵绝地求生等 7 大系统的详细设计。
   * **适用人员**：策划、数值、前端交互开发、剧情文案。

2. **[技术设计与架构规范（TDD）](./TDD_TECHNICAL_ARCHITECTURE.md)**
   * **内容**：系统分层架构、数据契约模型、PRNG 确定性伪随机数算法（Mulberry32）、DAG 分支地图生成算法、无序配方匹配引擎、QTE 毫秒判定、`GameState` 状态机改造与 LocalStorage V1 $\to$ V2 无损迁移策略。
   * **适用人员**：前端架构师、引擎与核心逻辑研发工程师。

3. **[工程排期与里程碑规划（Roadmap）](./ROADMAP_SPRINT_SCHEDULE.md)**
   * **内容**：4 个 Sprint 迭代计划（Sprint 1: 探索与合成基石 $\to$ Sprint 2: 职场人脉与微玩法 $\to$ Sprint 3: 动态巡逻与每日挑战 $\to$ Sprint 4: 模式扩展与全网发布）、24 个细分研发任务清单（WBS）、依赖矩阵图与验收测试用例。
   * **适用人员**：项目经理、敏捷教练、全体研发成员。
